# VAANI Launch Visual Identity

## Principle

Real VAANI captures are the product source of truth. Supporting motion graphics may illustrate the communication problem and architecture, but never imitate VAANI UI or live provider output.

## Palette

- Ink: `#111111`
- Surface: `#1A1A1A`
- Warm paper: `#F5F0E8`
- Accent: use the existing VAANI in-app accent only
- Text: high-contrast white/ink; no gradient text for essential copy

## Type and motion

Use the existing VAANI wordmark/title treatment where available. Captions use a clean sans serif with generous line height. Motion is restrained: 8–16 frame fades, typography reflow, and simple screen-card transitions. Avoid faux terminal/code effects, exaggerated AI particles, and cultural stereotypes.

## Screen treatment

Show original recordings unaltered inside a minimal device crop/frame. Each capture receives a small caption stating exactly what it shows (for example, “Android local UI — emulator validation”). Never overlay a claim that the capture does not prove.

## Aspect ratios

- Primary: 1920×1080, 30 fps.
- Vertical: 1080×1920, recomposed rather than cropped.
- Feature clips: 16:9 or 9:16 according to distribution.
