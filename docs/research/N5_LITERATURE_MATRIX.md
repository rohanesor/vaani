# N5 — Literature Matrix: Semantic & Acoustic Tokens for Offline Emergency Communication

This matrix compiles and evaluates foundational and state-of-the-art research papers across speech semantic communication, neural audio codecs, discrete tokenizers, task-oriented communications, emergency ontologies, and on-device NLP. Every paper is critically assessed against the constraints of **Vokie / iTantra** (offline, Android ARM64 low/mid-range, PacketV2, BLE/Wi-Fi Direct, 10 Indian languages).

## Synthesis of Literature Findings for Vokie / SIH

1. **Physical Layer JSCC vs. Application Layer Semantics:**
   Academic papers on "DeepSC-S" (Weng & Qin) assume an end-to-end continuous channel where neural network activations modulate analog radio symbols directly. This is **fundamentally incompatible** with Vokie's existing production architecture, which operates on digital packet transports (Bluetooth RFCOMM, BLE, and Wi-Fi Direct) using standard Android hardware stacks. Vokie requires **digital, packetizable semantics**.

2. **Acoustic Tokens vs. Text Payload:**
   Neural audio codecs (EnCodec, SoundStream, DAC, Mimi) compress raw 256 kbps audio to 1.5–6.0 kbps (750 to 3,000 bytes for a 4s message). However, Vokie's existing pipeline **already performs local STT on the sender**, producing 50–200 bytes of UTF-8 text. Transmitting acoustic tokens would consume **5x to 20x more bandwidth than text**, increase battery consumption on low-end ARM64 processors, and completely destroy Vokie's core capability of **multilingual cross-translation** at the receiver.

3. **Discrete Semantic Tokens vs. Structured Semantic Frames:**
   Discrete semantic tokens (e.g. SpeechTokenizer Layer 1, HuBERT k-means) produce ~250 bps (125 bytes for 4s), which is roughly the same size as UTF-8 text, but requires a 100M+ parameter model on device. In contrast, **Task-Oriented Structured Semantic Frames** (OASIS CAP / Joint Intent-Slot) compress actionable emergency meaning into **16 to 32 bytes**.

4. **Information Loss in Emergency Scenarios:**
   The literature overwhelmingly confirms that compressing speech to purely discrete semantic labels risks catastrophic information loss (e.g. omitting victim counts, locations, or negation). Therefore, in life-critical rescue communications, **the original text MUST NOT be discarded**. Semantics must be transmitted as high-priority metadata alongside text, or as an emergency beacon fallback when the link cannot support full packets.
