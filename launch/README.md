# VAANI Launch Production

Reusable Remotion source is in `remotion/`. It deliberately renders only evidence-safe typography until approved real captures are supplied externally. Do not add generated screens or provider outputs as product footage.

Preview locally with the repository-local Remotion CLI after installing dependencies. Renders, recordings, exports, and generated supporting assets are ignored by git and must be referenced in `docs/VAANI_RECORDING_MANIFEST.md`.
